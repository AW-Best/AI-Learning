认识一下

GitHub 是什么、怎么来的

  • 定位：全世界程序员存代码、给别人看、一起改的地方——代码版的"作品集 + 协作网"。
  • git ≠ GitHub：git 是你电脑里的时光机；GitHub 是把它搬上云端、给你一个能分享的链接的网站。
  • 发展：2008 年上线 → 今天全球一亿多开发者、几亿个项目，最大的代码集散地。
  • 2018 年微软花 75 亿美元买下它——一个"放代码的网站"值这么多，因为代码是这个时代最值钱的东西之一。

别人能看、能点赞（⭐ star）、能照着学。你的猜拳大师传上去 = 第一个全世界能打开的作品。

为什么这跟你有关

大模型会写代码，是 GitHub "喂"出来的

  • ChatGPT、Claude 为什么张口就能写代码？因为训练时读了海量公开代码，GitHub 这类平台就是最大的来源。
  • 你在 GitHub 上看到的每个项目，某种意义上都成了 AI 的"教材"。
  • 所以你 push 上去的代码，既是你的作品，也在加入"人类教 AI 写代码"的大库。
  • GitHub 自己也做了 Copilot——最早帮你写代码的 AI 助手，就长在这上面。

GitHub 不只是网盘，是人类协作 + AI 学习的代码中枢。你现在做的，正在这条线上。

带回家 · 让 AI 改的完整循环

改之前存档,改之后检查

# ① 改之前：先存一份能跑的 git add . git commit -m "改之前·能跑的版本" # ② 让 AI 只改一个目标……改完 # ③ 自己检查 git diff # 它改了哪几行？ python game.py # 还能跑吗？ # ④ 满意就存，不满意一键退回 git commit -am "加了出拳统计" git restore . # ← 不满意时用这一句

每次只改一个目标。攒一大坨再 commit，出事就找不到是哪步坏的。

带回家 · 改飞了怎么救

先看你在哪一步,再敲对应那句

还没 git add（最常见） git restore game.py ← 退回上次存档 已经 git add 了 git restore --staged game.py ← 先从待存区拿出来 git restore game.py ← 再退回 想退回更早的版本 git log --oneline ← 找到那行前面的编号 git restore --source=9a3f1c game.py

不确定在哪一步？先敲 git status，它会告诉你。
